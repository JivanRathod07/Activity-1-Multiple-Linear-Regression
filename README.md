House Price Prediction using Multiple Linear Regression
Project Overview
This project predicts the price of a house using Multiple Linear
Regression. The model uses different house features such as area, number
of bedrooms, bathrooms, stories, parking, and other facilities to
estimate the house price.
Activity
Activity 1: Multiple Linear Regression
Dataset Information
- Dataset name: Housing Prices Dataset
- Source: Kaggle
- Dataset link:
  https://www.kaggle.com/datasets/yasserh/housing-prices-dataset
- File name: Housing.csv
- Dataset size: 545 rows and 13 columns
- Target column: price
The dataset contains numerical and categorical features related to
houses, including: - Area - Bedrooms - Bathrooms - Stories - Main road
access - Guest room - Basement - Hot water heating - Air conditioning -
Parking - Preferred area - Furnishing status
